# Chapter 11 종합 프로젝트

[이전 Chapter 10](chapter-10.md) · [웹 보안 커리큘럼](curriculum.md)

메모 조회, 검색, 인사 화면, 상태 변경, 프로필 수정에서 3~5개를 선택하세요. 각 기능의 정상 동작을 먼저 적고, 신뢰 경계와 필요한 검사를 코드에서 찾은 뒤 수정과 회귀 테스트를 작성합니다.

1. **기준 기록.** 앱을 재시작해 예제 데이터를 초기화하고 정상 입력의 상태 코드와 결과를 적습니다.
2. **원인 설명.** 외부 입력이 들어오는 위치와 서버에서 해당 입력을 해석하거나 권한을 확인하는 지점을 표시합니다.
3. **수정.** 객체 소유권 검사, 쿼리 바인딩, 출력 이스케이프, 세션 토큰 검증, 속성별 허용 목록 중 원인에 맞는 방어를 적용합니다.
4. **회귀 테스트.** 정상 기능이 유지되는지, 정책에 맞지 않는 요청이 거부되는지, 거부한 뒤 저장값이나 권한이 유지되는지 확인합니다.
5. **결과 기록.** 검증 수단이 Flask 테스트 클라이언트, 실제 HTTP, 브라우저, 오프라인 모델 중 무엇이었는지 표시합니다. [최종 보고서 양식](../report-template.md)

**확인 문제.** 테스트 클라이언트가 HTML 응답을 받았다는 사실과 브라우저가 그 HTML을 화면에 어떻게 해석했는지는 각각 어떤 검증으로 확인할 수 있나요?

**제출물.** 패치, 테스트 코드, 결과 기록과 보고서를 제출하세요. 보고서 한 항목에서 정상 동작, 원인, 수정 이유, 재검증 결과를 이어서 읽을 수 있어야 합니다.
