# 최종 프로젝트 및 취약점 보고서

## 프로젝트 범위

- 대상: 로컬 실습 앱과 예제 코드
- 목표: 취약점 3~5개를 재현하고 직접 수정하여 회귀 테스트로 검증
- 제출물: 이 보고서, 수정 코드, 테스트, 필요한 요청·응답과 화면 기록
- 초기화: 앱 재시작으로 DB·세션을 초기화하고 계정·메모 소유권 확인
- 검증 구분: 테스트 클라이언트 / 실제 HTTP / 브라우저 / 가상 서비스 모델

1. 초기 상태를 만든다.
2. 정상 요청을 보낸다.

4. 응답 및 실제 서버 상태 변화를 확인한다.

```http

Host: 127.0.0.1:5000
```

## 프로젝트 완료 점검

- [ ] 독립적인 취약점 3~5개에 재현 근거가 있다.
- [ ] 원인과 수정 이유가 코드와 연결된다.
- [ ] 공격 차단과 정상 기능 유지가 모두 검증된다.
- [ ] 테스트 결과와 수동 확인 결과를 구분했다.

- [ ] 로그·화면·요청에서 쿠키·토큰·비밀번호를 가렸다.
